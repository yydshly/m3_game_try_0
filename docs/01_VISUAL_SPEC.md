# 01_VISUAL_SPEC - AI 小镇生活视觉目标

## 核心目标

把当前项目从“功能原型页面”改造成“治愈系小镇模拟游戏主界面”。

最终观感应该接近参考图：

- 桌面端：`reference/desktop-target.png`
- 移动端：`reference/mobile-target.png`

## 风格关键词

- 治愈
- 温暖
- 可爱
- 小镇地图
- 轻经营
- 手账感
- 居民角色感
- AI 管家陪伴感

## 视觉层级

### 1. 顶部 HUD

顶部不是普通 Header，而是游戏 HUD。

必须包含：

- `AI 小镇生活`
- `🏡 治愈系小镇模拟`
- Day
- 当前阶段：早上 / 下午 / 晚上
- 舒适度
- 物资
- 精神值

视觉要求：

- 奶油白 / 暖米色背景
- 大圆角卡片
- 柔和阴影
- 小图标 + 数值 + 进度条
- 不要后台表格感

### 2. 中央小镇地图

这是最重要部分。

必须让用户第一眼看到：

- 花园
- 餐厅
- 工坊
- 广场
- 森林
- 居民位置
- 当前最新动态气泡

视觉要求：

- 草地渐变背景
- 路径感
- 地点像地图节点，不是普通列表卡片
- 居民像角色标记，有头像感、名字、任务图标
- selected 居民要有明显光环/边框
- hover 有上浮

### 3. 左侧操作面板

像游戏操作区，而不是表单。

包括：

- 今日目标
- 推进阶段
- AI 管家安排
- 结束今天
- 管家提示

主按钮必须有游戏感：

- 大
- 圆角
- 有图标
- 有渐变
- 有按压反馈

### 4. 右侧居民详情

像角色面板。

必须包含：

- 头像
- 姓名
- 职业
- 角色描述
- 心情条
- 体力条
- 需求：休息 / 社交 / 成就
- 当前任务
- 当前想法
- 最近记忆

### 5. 底部故事区

底部不是杂项，而是故事沉浸区。

包括：

- 📟 小镇动态
- 💕 邻里关系
- 📰 小镇日报

日报要像小报纸 / 手账卡片。

## 禁止方向

- 不要做成 SaaS 后台
- 不要冷色科技风
- 不要大面积纯白
- 不要密密麻麻的数据表
- 不要只用 emoji 堆砌
- 不要让地图变成普通卡片列表
